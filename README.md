# Laboration 1 – TypeScript 👩🏼‍💻

Detta repository innehåller en enkel webbapplikation för att hantera kurser.  
Applikationen är byggd med TypeScript och Vite och låter användaren lägga till, visa och ta bort kurser.

---

## Syfte 🏁

Syftet med uppgiften är att:

- förstå grunderna i TypeScript
- arbeta med typning av variabler och funktioner
- använda Vite för att skapa en webbapplikation
- hantera data med localStorage
- manipulera DOM med TypeScript

---

## Tekniker 🧩

- TypeScript
- Vite
- SCSS
- HTML
- LocalStorage
- Git & GitHub

---

## Funktionalitet ⚙️

Applikationen innehåller följande funktioner:

- lägga till kurser via formulär
- välja kurs från en lista (JSON) för autofyll
- validering av unik kurskod
- visa tillagda kurser i en lista
- ta bort enskilda kurser
- ta bort alla kurser
- sortera kurser efter namn
- spara och hämta data från localStorage

---

## Data 📦

Applikationen använder en JSON-fil som innehåller fördefinierade kurser.  
Dessa används för att snabbt kunna fylla formuläret.

## Det här tar jag med mig från uppgiften 🙌

I den här uppgiften har jag fått en första förståelse för hur TypeScript används i praktiken. Till en början upplevde jag inte någon jättestor skillnad jämfört med JavaScript, eftersom applikationen är relativt liten.

Det som dock blivit tydligare är hur typning hjälper till att skapa struktur i koden, särskilt när man arbetar med objekt och funktioner. Genom att definiera interfaces och typer blir det lättare att se hur data ska se ut och undvika fel.

Jag tar framför allt med mig:

- hur man definierar och använder interfaces
- hur man begränsar värden med egna typer (t.ex. progression A, B eller C)
- hur TypeScript kan hjälpa till vid DOM-manipulation genom tydligare typer
- hur typning kan göra koden mer förutsägbar och lättare att förstå

Även om skillnaden inte alltid känns så stor i mindre projekt, förstår jag att TypeScript kan bli mer värdefullt i större applikationer.
